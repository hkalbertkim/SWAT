# SWAT v0.4 — locked 40× / 70% full-task evaluation

## Nonnegotiable target

For **N distinct, preselected tasks**, at least `ceil(0.70 * N)` must individually achieve `>= 40×` measured **full-task model token** reduction while both baseline and SWAT pass verification. Every selected task remains in the denominator, including unstarted, failed, timeout, incomplete, or missing runs. Repetitions never create extra tasks.

Each task has 3 paired repetitions. All six executions must complete and pass, and the **median of the three paired total-token ratios** must be >= 40 to qualify. A 100-task sample needs >=70 qualifying tasks, not a 40× population average. Results from a 100-task sample cannot be generalized to all 642 tasks without running the full split.

## How to score

```bash
python3 benchmarks/fulltask/evaluate.py OBSERVED_RUNS.jsonl \
  --manifest benchmarks/fulltask/swebench_pro_v2_pilot100.json --summary-only

python3 -m unittest discover -s benchmarks/fulltask -p 'test_*.py'
```

Input observations must originate from genuine agent runtime usage and independently verified task outcomes, after executing the official isolated graders. Missing runs are *not* filled in or silently dropped.

## Execution environment gate

The host has `colima` installed but not running. Docker CLI and Harbor were not detected, and the target benchmark containers/verifiers are not active. Installing/changing system-wide container tools is intentionally separate from this scorer and is **not evidence of benchmark performance**. Do not run benchmark-supplied untrusted repository tests directly on the personal Mac without appropriate sandboxing. For official Pro V2 use isolated images, locked network settings, genuine task grading, and no reference patch leakage.

## Pivot decision if SWAT misses the goal

A prompt-only skill cannot enforce runtime cache hits, deterministic execution, or prevent the model's compulsory context overhead. If 40× on 70% is not observed, test genuinely different approaches rather than polishing the prompt: safe read-only tool-call reuse, local deterministic routing, and previously validated artifact reuse. Run these as distinct, clearly labeled variants. **Do not describe them as SKILL.md-only savings.**

No headline claiming 40× is authorized until the locked official tasks have run and passed the external evaluation gate.
