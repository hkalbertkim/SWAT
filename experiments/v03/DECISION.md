# SWAT v0.3 — two-track decision

Track B: consolidated minimal Skill. Cut the current long rulebook to 3 operational rules and load it only for relevant workflows. Ship first, validate real task completion.

Track A: find narrowly scoped 10× reductions in duplicate read-only work after partial-chain failures. Keep it as an experimental hypothesis with a clear falsification path, not a public headline.

Research findings: preserving context is more important than indiscriminate output trimming; prompt overhead and recovery work can negate token savings. Measure entire completed task, not a single call.

No KORA runtime integrations now. Track hypotheses separately. Do not advertise 10× until a controlled replicated benchmark demonstrates it.
